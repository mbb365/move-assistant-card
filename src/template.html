Connect Apple Health

Apple Health can't talk to Home Assistant directly. Your iPhone sends the numbers using the Shortcuts app and the Home Assistant Companion app. Set it up once and it runs by itself.

  1. Make a place for the number in Home Assistant Settings → Devices & services → Helpers → Create helper → Number. Name it Health steps. Minimum 0, maximum 100000, step 1, unit steps, display mode Input field.
  2. Build the shortcut on your iPhone Open Shortcuts → Automation → + → App → choose Home Assistant → Is opened → Run immediately. Add these actions in order: Find Health Samples — Type Steps, Start date is today, Group by Day, Limit 1 Get Details of Health Samples — Value Home Assistant → Call service (or Perform action) — input_number.set_value, entity input_number.health_steps, value = the step count from above
  3. Keep it fresh during the day Add a few more automations with the same actions using Time of day (for example 10:00, 14:00, 18:00, 22:00), also set to Run immediately.
  4. Pick it in Move Assistant Settings → Integrations → Steps → Health steps.
Other Health data Use the same recipe for anything in Health, for example exercise minutes, active energy or stand hours. Make one Number helper per value, then change the Type in Find Health Samples.
Check the number Run the shortcut once by hand and compare it with the Health app. Group by Day stops your iPhone and Apple Watch steps being counted twice.
